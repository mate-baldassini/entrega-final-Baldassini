# 🛍️ Entrega Final - Baldassini

Proyecto final desarrollado como parte del curso de **Desarrollo Web / JavaScript**.  
La aplicación fue construida utilizando **HTML**, **CSS** y **JavaScript**, con un enfoque en la interacción del usuario y la manipulación dinámica del DOM.

---

## 🚀 Funcionalidades principales

- Navegación y estructura responsive.
- Interactividad mediante JavaScript puro (sin frameworks).
- Manipulación del DOM para mostrar, agregar o eliminar elementos.
- Uso de arrays, objetos y funciones para manejar la lógica.
- Almacenamiento de datos en **LocalStorage** o similar (si aplica).
- Diseño limpio y adaptable a distintos tamaños de pantalla.

---

## 🧩 Tecnologías utilizadas

- **HTML5** → estructura y semántica.  
- **CSS3** → estilos, layout y responsive design.  
- **JavaScript (ES6+)** → lógica, eventos y manejo de datos.  
- **Node.js y npm** → para gestión de dependencias (si aplica).  

---

## ⚙️ Instalación y ejecución

1. Clonar este repositorio:
```bash
   git clone https://github.com/mate-baldassini/entrega-final-Baldassini.git

2. Ingresar al directorio del proyecto:
```cd entrega-final-Baldassini```

3.Instalar dependencias:
npm install

4. Ejecutar el proyecto:
npm start
